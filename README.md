# Juegos de Vocabulario

Plataforma web bilingüe y modular para crear lecciones de vocabulario, abrir sesiones de juego y consultar resultados por estudiante y clase.

## Primera etapa

- Aplicación del profesor y del estudiante.
- Español e inglés.
- Modo claro y oscuro.
- Galería modular de actividades.
- Preparación para GitHub Pages y Supabase.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

La configuración local de Supabase se guarda en `.env.local`. Nunca se deben incluir claves secretas o `service_role` en el repositorio.
